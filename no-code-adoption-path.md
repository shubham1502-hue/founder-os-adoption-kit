# No-Code Adoption Path

This kit is manual-first. Level 1 is the default path.

## Level 1: Manual no-code path

Use this when you are trying the workflow for the first time.

- Copy the template.
- Fill sample data.
- Use the founder prompt.
- Generate output.
- Review weekly.

Recommended tools:

- Google Sheets
- Google Docs
- Notion
- CSV file in a private folder

Do not connect live systems yet. The goal is to prove that the decision workflow is useful.

## Level 2: Semi-automated path

Use this after the manual workflow is useful for 2 to 4 cycles.

- Keep Google Sheets as the source.
- Use ChatGPT, Gemini, Claude, or another assistant for output generation.
- Store outputs in email, Google Docs, or Notion.
- Add a weekly reminder to update the table.

This is still mostly manual, but the input and output rhythm becomes repeatable.

## Level 3: Advanced path

Use this only after the team trusts the manual workflow.

- n8n for routing and orchestration
- MySQL for action logs
- GitHub module routing for README-backed context
- Automated founder digests

Automation should reduce repeated manual work. It should not replace founder judgment.
