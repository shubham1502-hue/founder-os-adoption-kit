# Founder OS Lite

Founder OS Lite is the starter stack for founders who want value in one week.

It includes only:

1. [Revenue Rescue Kit](../starter-kits/revenue-rescue-kit/README.md)
2. [Weekly Review Kit](../starter-kits/weekly-review-kit/README.md)
3. [Investor Update Kit](../starter-kits/investor-update-kit/README.md)

Do not start with the full Founder OS ecosystem. Use these three kits first because they cover near-term revenue, weekly operating clarity, and external narrative.

## One-week cadence

Monday: Revenue Rescue

- Review stuck deals.
- Pick the top 3 follow-ups.
- Assign owner and deadline.

Wednesday: Weekly Review

- Review metrics, blockers, and owner actions.
- Decide what needs founder attention.
- Confirm next-week priorities.

Friday: Investor or board narrative cleanup

- Convert weekly signal into investor-safe language.
- Identify risks, asks, and next month priorities.
- Save the draft in a private doc.

## Rule

Use one kit at a time. Add deeper modules only when the manual workflow is useful.
