# Operator Guide

This guide is for Founder Office, BizOps, RevOps, and startup operators helping a founder adopt the kit.

## Operating principles

- Start with one problem.
- Use synthetic data first.
- Keep private company records in private tools.
- Do not introduce automation before the founder trusts the output.
- Turn every output into an owner, action, and deadline.

## Suggested operator workflow

1. Ask the founder which problem is most urgent this week.
2. Open the matching kit.
3. Copy the input template into a private sheet.
4. Fill 5 to 10 rows.
5. Paste the table into the founder prompt.
6. Review the output for unsupported assumptions.
7. Assign owner actions in the weekly review.
8. Save the memo in the company operating workspace.

## Quality bar

The output should be concise, specific, and ready for founder review. If the output sounds generic, tighten the input data and ask for clearer owner actions.
