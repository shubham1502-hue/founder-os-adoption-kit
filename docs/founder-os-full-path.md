# Founder OS Full Path

The full Founder OS is optional. Most founders should not start here.

Use the full path only after one or more manual kits are useful and repeated.

## Suggested progression

1. Use [Founder OS Lite](founder-os-lite.md).
2. Add onboarding risk if closed-won customers are getting stuck.
3. Add hiring bottleneck if team capacity is slowing execution.
4. Add AI workflow ROI when deciding what to automate, hire for, outsource, or keep manual.
5. Add RevOps infrastructure when the CRM and handoffs need stronger operating design.
6. Add n8n only after the manual workflow has a stable input, output, owner, and cadence.

## Full system principle

Founder OS is modular. Use one operating kit first. The full system is a map, not a requirement.
