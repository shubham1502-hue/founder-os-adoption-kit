# When To Use Which Kit

| Current situation | Use this kit | Do this first |
| --- | --- | --- |
| Follow-ups are slipping and deals are quiet | [Revenue Rescue Kit](../starter-kits/revenue-rescue-kit/README.md) | Fill the 5 highest-value active deals |
| The weekly review feels like scattered updates | [Weekly Review Kit](../starter-kits/weekly-review-kit/README.md) | Fill one row per operating area |
| An investor update is due this week | [Investor Update Kit](../starter-kits/investor-update-kit/README.md) | List highlights, metrics, risks, asks, and next steps |
| New customers are not reaching activation | [Onboarding Risk Kit](../starter-kits/onboarding-risk-kit/README.md) | Fill the riskiest onboarding accounts |
| Hiring decisions are delayed | [Hiring Bottleneck Kit](../starter-kits/hiring-bottleneck-kit/README.md) | Fill candidates who have been in stage longest |

## Choosing rule

Choose the kit that answers the founder decision you need this week.

Do not choose a deeper repo because it looks more complete. Start with the no-code kit, then go deeper only if the workflow is useful.
