# Google Sheets Template Index

Use these CSV files as Google Sheets templates. Copy the headers into a private sheet, then add 5 to 10 rows.

| Template | Use when | Source file |
| --- | --- | --- |
| Revenue rescue | Deals are stuck or follow-ups are slipping | [starter-kits/revenue-rescue-kit/input-template.csv](../starter-kits/revenue-rescue-kit/input-template.csv) |
| Weekly review | Weekly leadership review is messy | [starter-kits/weekly-review-kit/input-template.csv](../starter-kits/weekly-review-kit/input-template.csv) |
| Investor update | Investor update is due | [starter-kits/investor-update-kit/input-template.csv](../starter-kits/investor-update-kit/input-template.csv) |
| Onboarding risk | Customers are not activating | [starter-kits/onboarding-risk-kit/input-template.csv](../starter-kits/onboarding-risk-kit/input-template.csv) |
| Hiring bottleneck | Hiring pipeline is stuck | [starter-kits/hiring-bottleneck-kit/input-template.csv](../starter-kits/hiring-bottleneck-kit/input-template.csv) |

## How to use

1. Create a private Google Sheet.
2. Paste the template header into row 1.
3. Add 5 to 10 rows of synthetic or private company data.
4. Copy the table into the matching founder prompt.
5. Save the output in a private doc or operating review.
