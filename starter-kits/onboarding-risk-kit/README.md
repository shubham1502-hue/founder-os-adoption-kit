# Onboarding Risk Kit

Use this kit when customers are not activating, setup is delayed, or blockers are hidden after close-won.

Underlying repo: [founder-customer-onboarding-os](https://github.com/shubham1502-hue/founder-customer-onboarding-os)

## What you need

- customer name or anonymized account name
- plan value
- onboarding stage
- last touch date
- activation status
- blocker
- owner
- risk level
- next action

## What you get

- accounts needing founder attention
- risk reason
- owner
- next action
- deadline

## Start manually

1. Open [input-template.csv](input-template.csv).
2. Copy the header into a private sheet.
3. Use [sample-input.csv](sample-input.csv) first.
4. Paste your table into [founder-prompt.md](founder-prompt.md).
5. Format the answer like [sample-output.md](sample-output.md).
6. Review high-risk accounts before the next customer success check-in.

Use anonymized customer names in any public example.
