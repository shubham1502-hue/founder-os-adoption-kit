# Revenue Rescue Kit

Use this kit when deals are stuck, follow-ups are slipping, or the founder does not know which revenue action matters this week.

Underlying repo: [founder-os-revenue-engine](https://github.com/shubham1502-hue/founder-os-revenue-engine)

## What you need

- 5 to 10 active deals
- current stage
- deal value
- last activity date
- next step
- owner
- risk level

## What you get

- top stuck deals
- revenue at risk
- recommended follow-up action
- draft follow-up message
- owner and deadline

## Start manually

1. Open [input-template.csv](input-template.csv).
2. Copy the header into a private sheet.
3. Use [sample-input.csv](sample-input.csv) first.
4. Paste your table into [founder-prompt.md](founder-prompt.md).
5. Format the answer like [sample-output.md](sample-output.md).
6. Run the top 3 follow-ups before the next revenue review.

Do not connect CRM automation until the manual workflow produces useful founder actions.
