# Weekly Review Kit

Use this kit when weekly leadership review is scattered across metrics, blockers, owner updates, and founder memory.

Underlying repo: [founder-weekly-operating-review-agent](https://github.com/shubham1502-hue/founder-weekly-operating-review-agent)

## What you need

- one row per operating area
- current and previous metric values
- status
- owner
- blocker
- next action

## What you get

- wins
- risks
- decisions needed
- owner actions
- next-week priorities

## Start manually

1. Open [input-template.csv](input-template.csv).
2. Copy the header into a private sheet.
3. Use [sample-input.csv](sample-input.csv) first.
4. Paste your table into [founder-prompt.md](founder-prompt.md).
5. Format the answer like [sample-output.md](sample-output.md).
6. Review owner actions in the next weekly founder meeting.

Keep the weekly review simple before adding deeper reporting.
