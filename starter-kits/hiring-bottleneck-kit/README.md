# Hiring Bottleneck Kit

Use this kit when hiring is slow, candidates are stuck, or founder hiring decisions are living in memory.

Underlying repo: [founder-hiring-talent-pipeline-os](https://github.com/shubham1502-hue/founder-hiring-talent-pipeline-os)

## What you need

- role name
- candidate name or anonymized candidate label
- current stage
- days in stage
- score
- concern
- next action
- owner
- urgency

## What you get

- stuck roles
- candidate actions
- decision owner
- urgency
- recommended next step

## Start manually

1. Open [input-template.csv](input-template.csv).
2. Copy the header into a private sheet.
3. Use [sample-input.csv](sample-input.csv) first.
4. Paste your table into [founder-prompt.md](founder-prompt.md).
5. Format the answer like [sample-output.md](sample-output.md).
6. Move the highest-urgency candidate action before the next hiring review.

Use anonymized candidate names in public examples.
