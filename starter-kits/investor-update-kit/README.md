# Investor Update Kit

Use this kit when an investor update is due and the founder needs to turn operating signal into a clear draft.

Underlying repo: [board-pack-investor-update-agent](https://github.com/shubham1502-hue/board-pack-investor-update-agent)

## What you need

- highlights
- metrics
- risks
- asks
- next steps

## What you get

- investor update draft
- highlights
- metrics
- risks
- asks
- next month priorities

## Start manually

1. Open [input-template.csv](input-template.csv).
2. Copy the header into a private sheet.
3. Use [sample-input.csv](sample-input.csv) first.
4. Paste your table into [founder-prompt.md](founder-prompt.md).
5. Format the answer like [sample-output.md](sample-output.md).
6. Review the draft before sharing externally.

Do not send AI-generated investor language without founder review.
